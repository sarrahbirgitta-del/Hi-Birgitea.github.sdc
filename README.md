# Birgitta Sarrah Kartika — Personal Portfolio

A responsive personal portfolio website with a modern, minimal navy, blue, and white visual identity.

## Files
- index.html — page content
- style.css — responsive styling
- script.js — page interactions

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select Pages from the sidebar.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose branch main and folder /(root), then click Save.
5. Wait for deployment. Expected project URL:
   https://sarrahbirgitta-del.github.io/Hi-Birgitea.github.sdc/

## Personalize before sharing
The email button is intentionally left without an address. Edit the mailto link in index.html and add your preferred public contact email before sharing the site.
